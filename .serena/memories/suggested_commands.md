# Suggested Commands

- **Run tests**: `make test` or `go test -v ./...`
- **Run linter**: `make lint` (requires `golangci-lint`)
- **Go vet**: `go vet ./...`
- **Generate docs**: `go generate ./...`
- **Generate changelog**: `make changelog` (requires `ghch`)
- **Install tools**: `make tools`
- **Clean**: `make clean`
